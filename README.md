# Sales Data Analysis (Excel)

## Overview
This project contains sales data maintained and analyzed using **Microsoft Excel** only.  
The purpose of this file is to store, view, and perform basic analysis on sales information.

## File Included
- `sales.xlsx` – Main Excel file containing all sales records and analysis.

## Requirements
You only need:
- Microsoft Excel (2016 or later)  
  

## How to Use
1. Download or open the file `sales.xlsx`.
2. Open it using Microsoft Excel.
3. Navigate through the sheets:
   - **Raw Data** – Original sales entries.
   - **Summary** – Aggregated results (totals, averages, etc.).
   - **Charts** – Visual representation of sales data.

## Features
- Data entry and storage
- Basic formulas (SUM, AVERAGE, COUNT)
- Pivot tables for summary
- Charts for visualization
